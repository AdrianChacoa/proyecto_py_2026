
# Sistema de Gestión de Productos 

Este proyecto consiste en un sistema de gestion de productos desarrollado en Python.El programa permite administrar productos mediante un menu interactivo en la consola.

## Tecnologias utilizadas

- Python 3.14
- SQLite
- Visual Studio Code

## Funcionalidades

1. Agregar productos.
2. Listar productos registrados.
3. Buscar productos por nombre.
4. Eliminar productos mediante su ID.
5. salir del sistema sin eliminar productos registrados. 

## Persistencia de datos

La informacion se almacena en una base de datos SQLite llamada productos.db. Los datos permanecen guardados cuando se cierra el programa y se recuperan al volver a ejecutarlo.

## Conclusion

El proyecto permite administrar productos de manera sencilla y demuestra el uso de funciones, estructuras de control, consultas SQL y persistencia de datos mediante SQLite.
